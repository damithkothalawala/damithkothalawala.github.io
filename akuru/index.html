akuru
BY DAMITH RUSHIKA KOTHALAWALA

Sinhala type.
Ready to explore.

A native macOS font manager with pre-generated previews for every catalog font. Browse the library and read සකස්කඩ before downloading a font. Install the fonts you choose, try your own text, and manage the Sinhala Wijesekara keyboard from the sidebar.

54 distinct families · 69 font files
Download Akuru 2.1.0Release details & checksums ↗

APPLE SILICON + INTEL · TARGETS MACOS 12.0 AND NEWER
Native UI reviewed on macOS 27; core tests and builds passed on macOS 26. Native macOS 12 runtime remains unverified.
Ad-hoc signed. This release is not notarized.
