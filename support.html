Your email app opens so you can review the message before sending it. Read the privacy policy for information about support correspondence.

What to include

  • Your Akuru version and whether you use the direct-download or App Store edition.
  • Your macOS version and whether your Mac uses Apple Silicon or Intel.
  • The font name or feature involved, the steps you followed and the exact error message.
  • A screenshot if helpful, with personal text and unrelated information removed.

Do not send passwords, recovery codes, private keys or confidential documents. Akuru does not automatically upload a support report.

Font previews and downloads

Akuru includes prepared Sinhala article previews, so browsing the bundled library does not require downloading each font. Custom text and character previews may need the selected font file. An internet connection is required for new catalog content, source-linked font downloads and a Wikipedia refresh.

If a download fails, note the font name and error. Source files can move or change; Akuru checks expected file integrity. Contact support instead of substituting an unverified file. Font licences and permission notes are available in the app, and the original authors retain their rights.

Installation and removal

Use the app’s Install and removal controls for fonts it manages. If another copy already exists, or Akuru reports a registration or removal problem, send the exact message to support before deleting files manually.

The App Store edition keeps managed font files in its app container and uses macOS font registration. The direct-download edition uses your account’s Fonts folder. These are different installation paths; tell support which edition you use.

For opening a direct-download version of Akuru, follow the installation guide on the homepage. The current and older-release instructions are identified there.

Dasun’s Wijesekara keyboard

The keyboard is created by Dasun Sameera Weerasinghe. The direct-download edition includes its installer and managed updater. The App Store edition contains keyboard credits and instructions, without keyboard installation or update checks.

After using the direct edition to install or update the keyboard, follow its instructions to sign out and back in and add the layout in macOS Keyboard settings. For a missing input-menu icon or duplicate layout, contact support before removing existing layouts.

Privacy or a problem with a font

Email admin@drklk.org for privacy questions, support-message correction or deletion requests, or help clearing local Akuru data. For a font-source, credit or permission correction, include the font name and a link to the original evidence.

The full font library and contributor directory are available inside the app. Find the current download and release information on the Akuru homepage.
